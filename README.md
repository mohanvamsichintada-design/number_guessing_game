# 🎯 Number Guessing Game

An interactive Number Guessing Game built with Python and Streamlit.

🌐 **[Play the Game Online](https://numberguessinggame-ihypbzzpcv669veinqfobb.streamlit.app/)**

## ✨ Features

- 🎮 Three difficulty levels
- 🟢 Easy: numbers 1–50 with 4 attempts
- 🟡 Medium: numbers 1–100 with 7 attempts
- 🔴 Hard: numbers 1–500 with 10 attempts
- ⬆️ Hint when the guess is too low
- ⬇️ Hint when the guess is too high
- 🎯 Attempt tracking
- 🔄 Play Again functionality
- 🌐 Deployed as a web application

## 🛠️ Technologies Used

- Python
- Streamlit
- Random module

## 🧠 Python Concepts Used

- Functions
- Conditional statements
- Loops
- Variables
- Parameters
- `if`, `elif`, `else`
- `random.randint()`
- Streamlit widgets
- Session state

## 🎮 How to Play

1. Choose a difficulty level.
2. Click **Start New Game**.
3. Enter your expected number.
4. Click **Guess**.
5. Use the hints to improve your next guess.
6. Guess the correct number before you run out of attempts.
